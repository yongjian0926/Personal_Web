## 网站内容

| 页面 | 内容 |
| --- | --- |
| 个人介绍 · About | 个人简介、GitHub 入口与联系方式 |

### 界面与交互

- **中英文切换**：各页面提供中文与英文界面。
- **深浅色主题**：默认跟随系统设置，支持手动切换并在浏览器中保存主题偏好。
- **响应式布局**：适配桌面与移动设备，提供移动端菜单和计算器底部导航。
- **简洁视觉**：以黑白与金色为主要配色，结合卡片、弹窗和过渡动画。

### 实用工具

- **屏保时钟**：全屏时钟与动态背景。
- **世界时钟**：展示联合国安理会五个常任理事国相关城市时间，并配有昼夜分界地图。
- **倒计时**：自定义计时，支持暂停、恢复及浏览器通知提醒。
- **秒表**：记录经过时间，支持最多 100 条分段记录。
- **指南针与水平仪**：通过移动设备传感器显示方向和倾斜状态；指南针还可显示经纬度与海拔。
- **外部服务入口**：快速打开 Apple 地图与 Bing 翻译。

### 计算器

- 基础运算与科学计算，支持角度制／弧度制切换。
- 函数绘图、几何对象、数值表及画布缩放。
- 多类单位换算与在线汇率换算。
- 计算历史记录、结果复制与中英文界面。

## 技术实现

网站采用 **HTML5、CSS3 和原生 JavaScript** 构建。各页面的样式与脚本直接写在 HTML 文件中，无需安装项目依赖或执行构建命令，也不需要自建后端服务。

| 技术 | 用途 |
| --- | --- |
| HTML / CSS / JavaScript | 页面结构、响应式布局、主题与交互 |
| Canvas / SVG | 函数绘图、动态背景与图形界面 |
| D3.js v7 / TopoJSON | 世界时钟地图渲染 |
| world-atlas | 世界地图数据 |
| localStorage | 保存主题偏好及计算器的语言设置、历史记录 |
| 浏览器 API | 通知、地理定位、设备方向与剪贴板功能 |

## 本地预览

下载或克隆仓库后，在项目根目录启动静态服务器。以 Python 3 为例：

```bash
python3 -m http.server 8000
```

然后在浏览器中打开 [http://localhost:8000](http://localhost:8000)。

也可以直接打开 `index.html` 浏览页面；涉及网络请求或浏览器权限的功能，建议通过本地服务器预览。

## 部署

项目可直接部署到 GitHub Pages、Cloudflare Pages、Netlify 等静态网站托管平台，无需构建步骤。部署时保留 HTML 与图片资源的相对路径，并将 `index.html` 放在网站发布目录的根部。

使用 GitHub Pages 时：

1. 将网站文件提交到仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**，选择保存网站文件的分支及发布目录；文件位于仓库根目录时选择 **/ (root)**。
4. 保存后等待发布完成。若使用自定义域名，在 **Custom domain** 中填写域名，并按 GitHub Pages 要求配置 DNS 和 HTTPS。

## 使用说明

- 世界地图、CDN 脚本和在线汇率依赖网络及第三方服务；汇率以页面显示的数据来源和更新时间为准。
- 地理定位、设备方向传感器、通知和剪贴板功能受浏览器支持及权限设置影响，部署时建议启用 HTTPS。
- 指南针和水平仪主要面向具备相应传感器的移动设备，读数受设备与环境影响。
- 倒计时提醒依赖页面运行及浏览器通知能力，关闭页面后不会继续提醒。
